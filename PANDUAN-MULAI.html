Panduan Mulai Ghost Ads Spy

Ghost Ads Spy adalah satu folder. Kamu membukanya di aplikasi Claude, lalu cukup mengetik yang mau diriset. Claude yang membuka iklan, menghitung umurnya, membuka halaman jualan pesaing, dan menyusun hasilnya di Papan Produk Winning. Kamu tidak perlu membuka apa pun.

Yang kamu dapat di folder ini

Ghost Ads Spy AgentClaude yang sudah dilatih meriset di folder ini. Dia yang membuka iklan, menghitung umurnya, dan membongkar landing page pesaing. Dipakai selamanya, tanpa biaya langganan ke kami.
Formula Kurasi GhostSaringan yang menilai tiap produk. Hasilnya satu angka di papan: Skor Ghost, 0 sampai 30. Makin tinggi, makin layak dijual.
Papan Produk WinningSatu halaman berisi semua hasil risetmu: produk, umur iklan, bukti iklan yang bisa diklik, landing page, dan harga kompetitor.
Vonis ValidasiCek ulang satu produk sebelum uang iklan keluar. Hasilnya LANJUT TES KECIL, PERLU BUKTI, atau TAHAN.
Contoh Riset NyataSatu riset sungguhan untuk dipelajari cara bacanya. Ketik buka contoh riset kapan saja. Contoh ini terpisah, tidak tercampur dengan papanmu.
Panduan MulaiHalaman yang sedang kamu baca.

Yang kamu butuhkan

  • Laptop atau komputer Windows atau Mac, atau cukup HP lewat jalur Claude di cloud (lihat bagian Pakai dari HP di bawah).
  • Akun Claude berbayar (Pro, Max, atau di atasnya). Akun Claude gratis tidak bisa, karena bagian Code di aplikasi Claude hanya ada di akun berbayar. Ini aturan dari Claude, bukan dari kami.
  • Aplikasi Claude untuk komputer, gratis diunduh di claude.com/download.
  • Internet, dan sebaiknya Google Chrome atau Microsoft Edge sudah terpasang. Kalau tidak ada, Claude mengunduh browser kecil sendiri.

Ghost Ads Spy tidak bisa dipakai di chat biasa aplikasi Claude. Harus lewat bagian Code, karena hanya di situ Claude bisa membuka iklan.

Langkah mulai, sekitar 10 menit

  1. Ekstrak file zip. Klik kanan file zip yang kamu terima, pilih Extract All (Windows) atau klik dua kali (Mac). Hasilnya folder bernama Ghost-Ads-Spy.
  2. Pindahkan folder itu ke tempat yang tetap, misalnya ke Documents. Jangan dibiarkan di Downloads, karena semua hasil risetmu nanti tersimpan di dalam folder ini.
  3. Pasang aplikasi Claude. Buka claude.com/download, unduh untuk Windows atau Mac, pasang, lalu masuk dengan akun Claude-mu.
  4. Buka bagian Code. Di aplikasi Claude, klik Code di bagian atas sisi kiri.
  5. Pilih foldernya. Di bawah kotak ketik ada dua pilihan. Pilihan pertama: pilih yang ada di kelompok Local (artinya dijalankan di komputermu). Pilihan kedua: klik, pilih Open folder…, lalu pilih folder Ghost-Ads-Spy yang tadi kamu pindahkan.
  6. Kalau Claude bertanya apakah kamu percaya folder ini, pilih ya. Folder ini memang dari kami.
  7. Ketik: mulai lalu tekan Enter.

Pertama kali, Claude menyiapkan browser risetnya dulu. Ini sekali saja, 2 sampai 10 menit. Sesudah itu Papan Produk Winning terbuka di browsermu. Papan masih kosong, hanya berisi petunjuk, sampai riset pertamamu selesai.

Pakai dari HP, tanpa laptop

  1. Simpan folder ini ke GitHub milikmu (repo pribadi), lalu sambungkan GitHub ke akun Claude di claude.ai/connect-github.
  2. Di aplikasi Claude di HP, buka Code, mulai sesi baru, dan pilih repo itu.
  3. Di pengaturan environment sesi, izinkan jaringan ke www.facebook.com, facebook.com, dan static.xx.fbcdn.net. Tanpa ini Facebook ditutup dan iklan tidak bisa dibaca.
  4. Ketik mulai, lalu Riset produk: niche ...
  5. Papan dikirim Claude ke chat dan bisa dibuka langsung di HP. Claude juga menyimpan hasilnya ke GitHub, jadi riset lama muncul lagi di sesi berikutnya.

Sesi cloud dihapus setelah selesai dan browser risetnya disiapkan lagi tiap sesi baru (2 sampai 10 menit). Itu normal. Kalau Claude bilang tidak bisa menyimpan ke GitHub, sambungkan ulang GitHub-nya.

Dari riset sampai iklan pertama

  • Riset: Riset produk: niche ... Claude memilih negara pembanding yang cocok untuk niche itu.
  • Validasi: Validasi ide: nama produk hasilnya vonis dan hitungan harga.
  • Bangun produk: Bangun produk: nama produk Claude menyusun halaman jualan, tiga teks iklan, dan rencana tes.
  • Ikuti panduan: buka PANDUAN-NGIKLAN.html untuk langkah demi langkah memasang halaman, Pixel, dan iklan pertama, lengkap dengan kotak centang.
  • Baca hasil tes: Baca hasil tes iklan: biaya Rp 150.000, 90 klik, 2 pembelian, harga Rp 49.000
  • Bagikan: Buat laporan PDF untuk Nama Klien
  • Pantau pesaing: Pantau iklan atau Jadwalkan pantau tiap minggu
  • Ada yang aneh: Periksa sistem

Iklan itu tes berbayar dan bukan jaminan untung. Pakai modal yang siap hilang. Kamu sendiri yang memasang dan membayar iklan di Meta, Claude menyiapkan bahannya.

Cara pakai

  • Semua perintah diketik di Claude Code, di kotak ketik tempat kamu tadi mengetik mulai. Papan hanya untuk membaca hasil.
  • Ketik yang mau kamu riset, misalnya Riset produk: niche pemilik bisnis online Ganti nichenya dengan bidang atau target pembeli yang kamu mau.
  • 10 sampai 30 menit kemudian papan terisi produk winning, lengkap dengan umur iklan, bukti iklan, landing page, harga kompetitor, dan Skor Ghost.
  • Mau cek ulang satu produk, atau punya ide sendiri? Ketik Validasi ide: nama produknya Vonis Validasi muncul di papan.
  • Mau lihat papan lagi? Ketik buka papan
  • Mau tahu iklan pesaing masih tayang atau tidak setelah beberapa hari? Ketik pantau iklan
  • Di papan ada saringan (iklan winning, sudah divalidasi, favorit), tombol favorit di tiap produk, dan Unduh CSV untuk membawa daftar produk ke spreadsheet.
  • Selama bekerja, Claude kadang meminta izin menjalankan sesuatu. Tekan Allow atau Yes. Itu Claude yang sedang membuka iklan dan menyusun papan.
  • Selama riset berjalan kamu boleh meninggalkannya, asal laptop tetap menyala dan tersambung internet.
  • Tidak ada jendela browser yang muncul saat Claude membuka iklan, dan kamu tidak perlu login Facebook.

Kalau ada kendala

  • Claude bilang komputer belum punya Python. Python adalah program gratis yang dibutuhkan alat ini. Jawab saja "ya, pasangkan", Claude yang memasangnya. Di Mac bisa muncul jendela bertombol Install, tekan tombol itu dan tunggu sampai selesai. Sesudahnya tutup aplikasi Claude, buka lagi, lalu ketik mulai.
  • Claude bilang Facebook tidak bisa dihubungi. Biasanya karena jaringan kantor, kampus, atau wifi umum menutup Facebook. Pindah ke wifi rumah atau hotspot HP, lalu ketik mulai lagi.
  • Tidak ada tulisan Code di aplikasi Claude. Pastikan akunmu berbayar dan aplikasinya versi terbaru.
  • Papan tidak terbuka sendiri. Buka folder Ghost-Ads-Spy, masuk ke folder papan, lalu klik dua kali file papan-produk-winning.html.

Yang perlu kamu tahu

  • Semua hasil riset tersimpan di folder papan di dalam folder Ghost-Ads-Spy. Selama folder itu tidak dihapus, riset lama selalu muncul lagi, walau kamu memulai chat baru.
  • Jangan mengubah atau menghapus file lain di dalam folder, supaya alatnya tetap jalan.
  • Iklan diambil dari Facebook Ads Library, halaman resmi Facebook yang terbuka untuk umum. Kalau Facebook mengubah halaman itu, pembacaan iklan bisa terganggu sampai kami mengirim pembaruan.
  • Papan berhenti di vonis. Setelah dapat ide yang layak, kamu bisa minta Claude di chat membantu membuat produknya.
  • Skor Ghost dan vonis adalah saran dari bukti yang ditemukan, bukan jaminan produk laku. Keputusan tetap di tangan kamu.
  • Sudah biasa memakai Claude Code di terminal? Masuk ke folder ini, jalankan claude, lalu ketik mulai.
